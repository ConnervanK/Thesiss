\chapter{Extended Wavelength-Sweep Figures}
\label{app:extended-sweeps}

\Cref{sec:hyp1-phaseplane} showed one representative scale from each of five
repeated parameter sweeps produced by \texttt{TimeLapse\_Processing.ipynb},
to keep the main narrative focused. This appendix gives the complete sweep
for each of those five analyses, across every wavelength scale that was
simulated. Figures here intentionally repeat the scale already highlighted
in \cref{sec:hyp1-phaseplane}, so that each full sweep is shown as a single,
self-contained reference figure.
